# F8 — COMENTAR V1 — Implementation Plan

> Ejecutar task-by-task con TDD estricto: RED observable → GREEN mínimo → suite focused → suite completa → Windows CI exact-head → scope audit → checkpoint durable. No saltar gates.

**Goal:** implementar un modo independiente `COMENTAR` que cree, edite y elimine anotaciones PDF reales usando exclusivamente PDFium, con Save As transaccional, validación save→reopen y preservación medida de estructuras no objetivo.

**Architecture:** `COMENTAR` no comparte workspace ni writer con `EDITAR`. El estado persistente es managed; `PdfCommentWriter` materializa anotaciones sobre una apertura fresca del source; `PdfCommentOutputValidator` reabre el temporal antes de publicación atómica. `PdfEditSourceFingerprint` y el patrón de preflight se reutilizan de forma concreta, sin crear un mega-writer ni una jerarquía genérica.

**Runtime:** Windows x64, WPF/.NET 10, `bblanchon.PDFium.Win32 156.0.8076`, xUnit. No se espera ningún NuGet nuevo.

**Spec canónica:** `docs/superpowers/specs/2026-10-10-f8-comments-v1-design.md`

## Global constraints

- Base F7 cerrada: `f4cd27a8e752071ca2ca4879b1eab84d52d188eb`.
