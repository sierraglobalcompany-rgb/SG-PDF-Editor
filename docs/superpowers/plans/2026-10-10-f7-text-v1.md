# F7 — Texto V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir edición conservadora de objetos de texto PDF reales dentro del modo `EDITAR`, con fallback TTF controlado, writer combinado imagen+texto y Save As transaccional.

**Architecture:** PDFium sigue siendo el único motor de edición. Texto F7 añade snapshots managed y workspace propio, pero comparte con imágenes F6 fingerprint, preflight, materialización y hardening del modo `EDITAR`; el writer abre el PDF una sola vez y aplica imágenes + texto antes de un único `GenerateContent` por página editada.

**Tech Stack:** Windows x64, C#/.NET 10, WPF, PDFium `bblanchon.PDFium.Win32 156.0.8076`, xUnit, PDFsharp solo para fixtures sintéticos ya permitidos, DejaVu Sans 2.37 como fallback únicamente si pasa el Gate de procedencia/licencia.

**Spec:** `docs/superpowers/specs/2026-10-10-f7-text-v1-design.md`

## Global Constraints

- Base aprobada: `feat/f6-images` @ `c6d762efca01d50bfe3932d1f05617190a464fc6`.
- Plan/spec viven en `design/f7-text-v1`; la ejecución debe crear `feat/f7-text-v1` desde el commit aprobado del plan y usar worktree aislado.
- KISS/YAGNI: no `Domain/Application/Infrastructure`, DI nueva, command bus, plugin system, generic PDF object graph ni segundo motor PDF.
- F7 V1 edita solo objetos `FPDF_PAGEOBJ_TEXT` top-level; no reflow, OCR, reading order, columnas, Form XObject text ni creación libre de cajas de texto.
- Un solo modo `EDITAR` y un solo `Guardar como...` para imágenes + texto.
- Estado persistente 100 % managed; ningún `IntPtr`/handle PDFium sobrevive a una operación nativa.
- Toda llamada PDFium usa `PdfiumRuntime.NativeGate`; nunca `lock(NativeGate)` ni reacquire del mismo semaphore.
- Fuente original solo bajo política conservadora; code point nuevo/duda usa una única TTF fallback pinneada.
- No fuentes del sistema como garantía de salida; no descarga runtime.
- Ningún paquete NuGet nuevo esperado.
- Firma criptográfica y PDF abierto con contraseña continúan `Block / Unknown`.
- Source != destination; temp sibling; reopen/validate antes de publish; cleanup en `finally`; fallo/cancelación no marca baseline.
- Preservación F7 se mide de nuevo con el writer combinado real; no copiar resultados F6.
- Manual Windows QA permanece `NOT RUN` hasta ejecutarse físicamente.
- No merge de PR #25/F6 ni merge a `main` sin aprobación explícita.

## Review Focus

1. **Texto fragmentado en varios objetos:** dos objetos visualmente contiguos deben seguir siendo dos objetos seleccionables/editables; Task 5 lo fija con fixture y assertions de ordinales separados.
2. **Render mode no soportado:** debe poder seleccionarse como información/read-only pero nunca mutarse; Tasks 5, 7 y 12 lo fijan.
3. **Unicode fuera de cobertura fallback o texto vacío:** `Aplicar` debe rechazarse sin dirty-state ni glifos silenciosamente faltantes; Tasks 2, 7 y 12 lo fijan.
4. **Imagen + texto en la misma página con índices sensibles:** todos los objetos se resuelven antes de remover/reinsertar y `GenerateContent` ocurre una sola vez; Tasks 8 y 9 lo fijan.
5. **Cancel/Block/fallo de Save As:** nunca publica parcial, nunca limpia dirty-state/baseline y nunca ejecuta writer tras decline/Block; Tasks 10–13 lo fijan.
