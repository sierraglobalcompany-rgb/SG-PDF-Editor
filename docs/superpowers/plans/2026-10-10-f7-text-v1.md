# F7 — Texto V1 Implementation Plan

> Ejecutar task-by-task con RED → GREEN → suite focused → suite completa → exact-head CI/checkpoint donde aplique. No saltar gates.

**Goal:** edición conservadora de objetos de texto PDF reales dentro del único modo `EDITAR`, con fuente original cuando sea segura y fallback TTF mediante **CID Type2 + `ToUnicode` + `CIDToGIDMap` explícitos**.

**Architecture:** PDFium sigue siendo el único motor. Texto F7 añade snapshots/workspace específicos, comparte fingerprint/preflight/writer/hardening con imágenes F6 y materializa imágenes + texto en una sola apertura del PDF.

**Runtime:** Windows x64, C#/.NET 10, WPF, PDFium `bblanchon.PDFium.Win32 156.0.8076`, xUnit. Ningún NuGet nuevo esperado. DejaVu Sans 2.37 es candidata de fallback solo si pasa provenance/license/hash/coverage.

**Spec canónica:** `docs/superpowers/specs/2026-10-10-f7-text-v1-design.md`

## Global constraints

- Base F6 cerrada: `c6d762efca01d50bfe3932d1f05617190a464fc6`.
- Rama de ejecución: `feat/f7-text-v1`.
- No segundo motor PDF, no framework genérico, no nueva DI/capas.
- Top-level `FPDF_PAGEOBJ_TEXT` únicamente; no reflow/OCR/Form XObject text.
- Un solo modo `EDITAR` y un solo `Guardar como...` para imágenes + texto.
- Estado persistente managed; cero `IntPtr` persistentes.
- Todas las llamadas PDFium bajo `PdfiumRuntime.NativeGate`.
- Fuente original solo bajo política conservadora por `Rune`.
- Fallback **NO usa `FPDFText_LoadFont`**: esa ruta quedó rechazada por evidencia Unicode.
- Fallback usa `FPDFText_LoadCidType2Font` con mapas explícitos.
- No fuentes del sistema como garantía de producto; no runtime download.
- Firma criptográfica/password-opened = Block/Unknown.
- Source != destination; temp sibling; reopen/validate antes de publish; cleanup en `finally`.
- Preservación F7 se mide de nuevo con writer combinado real.
- Manual Windows QA permanece `NOT RUN` hasta ejecución real.
- No merge de PR #25/F6 ni merge a `main` sin aprobación explícita.

## Review focus

1. Objetos contiguos siguen separados.
2. Render mode no soportado = selectable/read-only, nunca mutado.
3. Rune fuera de cobertura / texto vacío = Apply rechazado sin dirty-state.
4. Imagen + texto same page: resolver todos los objetos antes de mutar; `GenerateContent` una vez.
5. Cancel/Block/fallo nunca publica parcial ni limpia baseline.
6. CID mapping debe reabrir Unicode **exactamente**, sin normalización silenciosa.
