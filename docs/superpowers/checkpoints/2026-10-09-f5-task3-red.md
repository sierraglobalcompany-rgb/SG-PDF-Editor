## 6. Política congelada que NO se debe reinterpretar

- `FPDF_GetSignatureCount(document) > 0` → **Block absoluto** en F5 inicial. Sin override.
- `PdfDocumentSession.OpenedWithPassword == true` → **Block absoluto** para output/import estructural de F5 inicial.
- Bookmark detectado → `Warning + Unknown`.
- Internal link/destination detectado → `Warning + Unknown`.
- Form detectado → `Warning + Unknown`.
- Named destinations, tagged structure, attachments, page labels y metadata detectables → no afirmar preservación; mantener como `Warning + Unknown` salvo evidencia posterior explícita.
- `UNKNOWN` nunca se presenta como preservado.
- Source PDF nunca se modifica.
- No añadir qpdf/pdfcpu/u otro motor preventivamente.

## 7. Precaución técnica importante

No envolver todo `Inspect(...)` en un único `PdfiumRuntime.NativeGate` si dentro se llaman métodos públicos existentes como `GetBookmarks()` o `GetPageLinks()`, porque esos métodos gestionan su propio acceso nativo y ya hubo anteriormente una corrección para evitar nested native gate (`fix(pdf): avoid nested native gate in navigation`).

Patrón seguro:

- usar los métodos públicos existentes de navegación fuera de un gate externo;
- para detectores raw nuevos, encapsular cada lectura nativa dentro del gate en `PdfDocumentSession.Organize.cs`;
- no exponer `IntPtr` de documento fuera de la capa PDF.
