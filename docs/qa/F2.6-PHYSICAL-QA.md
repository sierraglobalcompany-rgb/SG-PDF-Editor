Measurement guidance:

1. Use a ruler or caliper where practical.
2. Compare the physical printed geometry with the requested size and media loaded in the printer.
3. If Windows reports an imageable-area/clipping warning, record whether real output actually clips.
4. Record unexpected leading/trailing feed, centering or driver media substitution.
5. Do not change application scaling to make a failing printer/driver look correct; record the failure first.
