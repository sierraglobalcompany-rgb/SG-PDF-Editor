## Delivered

F3.3 adds a third local signature source without changing PDF placement/save architecture:

- WPF `InkCanvas` for native mouse/touch/stylus ink collection;
- Black `#000000` and Blue `#194196`;
- Thin 2.0 DIP, Medium 3.5 DIP, Thick 5.0 DIP;
- dialog-local Undo / Redo / Clear;
- useful-ink rejection for empty/tap/tiny drawings;
- transparent crop with bounded padding;
- 300-DPI-equivalent raster sampling (`300 / 96 = 3.125`);
- shared 20,000,000-pixel safety guard;
- output converges to existing `SignatureAsset`;
- `Dibujar firma...` integrated into the existing FIRMAR panel;
- cancel/failure preserves existing placements, selection and dirty state.

## Architecture ruling

F3.2 already owns the enum `SignatureInkStyle` (`Original/Black/Blue`). The initially planned drawn-ink helper name collided with that existing contract. The F3.3 helper was therefore named **`SignatureStrokeStyle`** while retaining `SignatureInkColor` and `SignatureInkWidth`. This is a naming-only ruling; no F3.2 behavior changed.
