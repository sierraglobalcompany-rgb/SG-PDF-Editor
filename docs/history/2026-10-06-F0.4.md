## Resultado

F0.4 añade cancelación cooperativa y una política latest-request-wins suficientemente pequeña para resolver rerenders automáticos obsoletos sin convertir el lector en una arquitectura de colas.

El caso práctico integrado es el auto-refit cuando el usuario está en Fit Page o Fit Width y cambia el tamaño del visor.

## Implementación

### 1. `PdfRenderScheduler`

Nueva pieza pequeña con una sola solicitud vigente:

- `Begin()` cancela la anterior y crea una nueva versión/token;
- `IsCurrent()` valida que una solicitud siga siendo la última;
- `CancelCurrent()` invalida la vigente;
- `Dispose()` cancela y libera el source activo.

No hay queue, worker pool, prioridades multinivel ni servicios adicionales.

### 2. PDFium cancelable

`PdfDocumentSession` conserva las firmas anteriores y agrega overloads con `CancellationToken` para:

- `GetPageSize`;
- `RenderPage`.

La espera de `PdfiumRuntime.NativeGate` usa el token. También se comprueba cancelación antes del render, después del render síncrono y antes de devolver/copiar el resultado.

Decisión técnica: no se intenta abortar `FPDF_RenderPageBitmap` durante la llamada. La función usada actualmente es síncrona; introducir progressive rendering solo para cortar esa llamada elevaría significativamente la complejidad. Se difiere hasta tener evidencia de latencia real que lo justifique.

### 3. Auto-refit controlado

`PdfScrollViewer.SizeChanged` se usa únicamente cuando el modo actual es `FitPage` o `FitWidth`.

Flujo:

1. llega resize;
2. `Begin()` invalida el resize anterior;
3. debounce de 150 ms;
4. se lee el viewport más reciente;
5. render en background con token;
6. antes de publicar se valida que la solicitud siga current y que sesión/navegación/zoom sigan siendo los mismos;
7. solo entonces se actualizan bitmap y DPI.

Zoom manual no hace auto-refit.

### 4. Prioridad de acciones explícitas

Antes de abrir otro PDF, navegar o aplicar zoom manual se cancela el auto-refit pendiente. Así una acción explícita del usuario prevalece sobre trabajo automático de resize.
