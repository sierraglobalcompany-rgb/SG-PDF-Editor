## Entregado

1. **Capability gate PDFium** — true invisible searchable Unicode text probado sobre el runtime pinneado.
2. **Tesseract local** — runtime Windows x64 y `spa`/`eng` pinneados, con provenance/digests/licencias; sin PATH global ni runtime download.
3. **Request / eligibility / process** — Español, Inglés, Español + Inglés; Automático, Página actual y Rango; threshold V1 de 20 code points alfanuméricos normalizados.
4. **Raster / TSV / geometry** — 300 DPI page-at-a-time, parser estricto y mapping a PDF space.
5. **Planner / writer / validator** — invisible text layer, Save As transaccional, source fingerprint, reopen/semantic validation y publicación atómica.
6. **Workflow / hardening** — preflight de firma/password, secuencial, cancelación/fallo sin publicación parcial, cleanup de temporales.
7. **WPF** — un comando `Herramientas → OCR / Hacer PDF buscable…`, diálogo mínimo, progreso, cancelación, NoOp y reopen por la ruta existente.
8. **Preservación** — corpus F10 propio con estructuras representativas, render del scan y payload decodificado de imagen source→output.

## Arquitectura congelada

```text
PDFium render
→ Tesseract recognition + TSV geometry
→ OcrTextLayerPlanner
→ PdfOcrWriter (PDFium)
→ semantic validation
→ atomic Save As
```

- PDFium sigue siendo owner principal del PDF.
- Tesseract reconoce; no genera el PDF final.
- qpdf 12.4.2 conserva su rol estrecho ya justificado y se reutiliza en el harness de preservación para extraer payloads decodificados.
- No segundo OCR engine ni segundo editor PDF.
- Sin cloud, backend, DB, account/auth, API keys, telemetry obligatoria ni runtime download.
- Source original protegido; Save As por defecto.
