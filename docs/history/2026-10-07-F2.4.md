# History — 2026-10-07 — F2.4 Layout + PDF Export

## Outcome

F2.4 reached **automated PASS** on `feat/f2-4-layout-pdf-export` / PR #16 draft. The slice adds physically exact label layout, sheet preview and local PDF export while preserving the project KISS/offline architecture.

## Product behavior added

- lazy quantity-to-output mapping for very large counts;
- exact millimeter layout planning;
- Thermal, A4, Letter and custom media;
- 1/2/3/4/6/8/10/12/custom grids;
- margins, gaps, portrait/landscape and 0°/90° label rotation;
- `Etiqueta | Hoja` WPF preview using existing managed Labelize PNG bytes;
- invalid layouts surface a reason and never silently resize labels;
- PDFsharp 6.2.4 local composition;
- same-directory transactional export preserving existing destination on failure;
- standard Windows `Guardar como PDF...` flow;
- exported PDF verification by reopening/rendering through existing PDFium.

## Dependency decision

PDFsharp entered only after geometry/preview were already green. Version `6.2.4` is pinned in app/test lockfiles. MIT license is stored in `third_party/licenses/PDFsharp-MIT.txt` and the dependency is recorded in `third_party/manifest.json`.

PDFsharp is **not** the PDF reader/editor engine; PDFium remains authoritative for reading/rendering.
