## Objetivo

Añadir navegación mínima y acotada al visor de F0.1: botones Anterior/Siguiente, indicador `Página X de N`, límites correctos y render de la página seleccionada sin bloquear el hilo UI.

## Implementado

### Estado de navegación

Se añadió `PageNavigationState` como clase inmutable con:

- `PageCount`;
- `CurrentPageIndex`;
- `CurrentPageNumber`;
- `CanMovePrevious`;
- `CanMoveNext`;
- `Previous()`;
- `Next()`.

El estado nunca produce índices fuera de rango. En la primera página `Previous()` conserva el índice `0`; en la última página `Next()` conserva `PageCount - 1`; un PDF de una sola página deshabilita ambas direcciones.

### UI WPF

- barra de navegación oculta hasta que hay un PDF cargado;
- botón `← Anterior`;
- indicador `Página X de N`;
- botón `Siguiente →`;
- botones deshabilitados según límites;
- navegación reiniciada a página 1 cuando se abre correctamente un nuevo documento;
- estado y status bar sincronizados con la página visible.

### Render y consistencia

La página candidata se renderiza con el `PdfDocumentSession.RenderPage(...)` existente dentro de `Task.Run`.

La UI solo reemplaza el estado y la imagen después de que el render termina correctamente. Si el render falla, se mantiene la página anterior y se muestra un error local.

Mientras una apertura o navegación está en curso:

- Anterior/Siguiente quedan deshabilitados;
- `Archivo > Abrir...` queda temporalmente deshabilitado;
- se valida que la sesión y el estado que iniciaron el render sigan siendo los activos antes de aplicar el resultado.

No se añadió scheduler/cancelación; eso permanece en F0.4.
