## Starting point

F2.2 was already automated PASS with Labelize 1.7.0 local rendering, managed PNG preview, design navigation and cancellation. F2.3 was approved as a bounded KISS slice: add output quantity semantics plus physical size/dpmm controls without starting F2.4 layout/PDF or F2.5 printing.

## Approved UX

Quantity:

- `Del archivo` — default, uses parsed `^PQ` per design;
- `Una de cada` — one output copy per printable design;
- `Personalizada por diseño` — same user-entered count for every printable design;
- quantity changes must not rerender preview.

Physical preview settings:

- 102×152 mm (4×6 in) default;
- 100×150 mm;
- 100×100 mm;
- custom width/height;
- 6 / 8 / 12 / 24 dpmm;
- physical setting changes rerender through Labelize, never stretch an existing PNG;
- successful rerender preserves selected design;
- failed rerender preserves the last valid preview/settings.
