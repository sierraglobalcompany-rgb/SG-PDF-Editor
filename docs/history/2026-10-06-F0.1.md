## Objetivo del slice

Implementar el mínimo vertical usable para PDF: seleccionar un PDF local desde la UI WPF, abrirlo con PDFium, renderizar la primera página a bitmap real y mostrarla, sin incluir navegación, zoom, scheduler completo, impresión ni otras funciones posteriores.

## Implementado

### UI

- `Archivo > Abrir...` conectado a `OpenFileDialog`.
- selección de un PDF local;
- trabajo de apertura/render mediante `Task.Run` para no ejecutar el render pesado en el hilo UI;
- creación de `BitmapSource` WPF desde buffer BGRA administrado;
- imagen mostrada en el panel central dentro de `ScrollViewer`;
- título/estado muestran archivo y `página 1 de N`;
- mensaje de error local cuando abrir/renderizar falla;
- al cerrar la ventana se libera la sesión activa.

### PDFium

Se añadieron únicamente los bindings necesarios para F0.1:

- `FPDFBitmap_Create`;
- `FPDFBitmap_FillRect`;
- `FPDFBitmap_GetBuffer`;
- `FPDFBitmap_GetStride`;
- `FPDFBitmap_Destroy`;
- `FPDF_RenderPageBitmap`.

La página se rasteriza a 96 DPI por defecto. Las dimensiones PDF en puntos se convierten usando `pixels = ceil(points × dpi / 72)`.

### Thread safety

`PdfiumRuntime` ahora posee el gate global requerido:

```text
SemaphoreSlim(1,1)
```

Las operaciones nativas de `PdfDocumentSession` pasan por ese gate: inicialización, apertura, conteo, tamaño, render, cierre y shutdown.

No se implementó todavía scheduler/prioridades/cancelación; eso permanece en F0.4.

### Memoria y handles

- `FPDF_PAGE` se cierra en `finally`;
- `FPDF_BITMAP` se destruye en `finally`;
- el buffer nativo se copia a `byte[]` administrado antes de liberar bitmap/page;
- la sesión/documento anterior solo se reemplaza después de abrir y renderizar correctamente el nuevo documento;
- `Dispose()` cierra el documento bajo el gate global.

## Auditoría

- P/Invoke contrastado con la API oficial de PDFium: bitmap de `FPDFBitmap_Create` usa 4 bytes por píxel y orden BGRx/BGRA; `FPDFBitmap_GetStride` se usa como fuente de verdad.
- `FPDFBitmap_FillRect` se trata como `FPDF_BOOL`/`int`.
- `FPDF_RenderPageBitmap` no conserva handles después del render.
- La memoria que recibe WPF ya es administrada.
- El slice no incorpora navegación/zoom/impresión/ZPL/firma/edición/OCR.
