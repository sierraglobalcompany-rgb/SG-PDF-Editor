## Result

- Both produced decodable Code128/QR in the synthetic corpus.
- Labelize measured about 59–61 designs/s.

- Labelize had a smaller packaging footprint.

## Decision

BinaryKits remains historical Gate evidence only and is not a fallback runtime engine.

Integration is local child-process CLI (`labelize.exe convert`), not HTTP/localhost, server mode, Rust C ABI or WASM host.
