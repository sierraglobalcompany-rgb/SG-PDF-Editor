## Goal

Print ZPL labels through normal installed Windows drivers while preserving the exact physical geometry already validated in F2.3/F2.4, with no silent shrink/stretch and no double quantity multiplication.

## Delivered

- [x] pure deterministic media/resolution/copy/imageable-area preflight policy;
- [x] media acceptance tolerance fixed at 0.5 mm per dimension for driver quantization only;
- [x] exact-size `LabelPrintPaginator`, one label per page, no printable-area fit;
- [x] F2.4 rotation semantics reused exactly once;
- [x] `Int32.MaxValue` paginator boundary protected without materializing all pages;
- [x] `PrintQueue` / `PrintTicket` / `PrintCapabilities` Windows adapter;
- [x] exact `PageMediaSize`, requested matching DPI when exposed, `CopyCount=1`;
- [x] `MergeAndValidatePrintTicket` followed by validated-size comparison;
- [x] `PageImageableArea` used only for clipping warnings, never scaling;
- [x] standard `PrintDialog` + preflight + explicit confirmation + spool submission;
- [x] confirmation includes printer, physical size, DPI, label count, Windows copies=1 and no SG PDF Editor scaling;
- [x] WPF `Imprimir etiquetas...` available only for a valid Thermal plan;
- [x] print cancel/success leaves document, quantities, render options, selected design and preview intact;
- [x] printing does not invoke Labelize again;
- [x] no new NuGet/runtime package.
