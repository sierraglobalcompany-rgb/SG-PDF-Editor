## Product contract

FIRMAR now has three creation sources:

1. transparent PNG;
2. photo/scan cleanup;
3. drawn signature through WPF InkCanvas.

All three converge to existing `SignatureAsset` and existing `AddSignatureAsset(...)`. No alternate PDF writer or placement path exists.

## F3.3 frozen behavior

- WPF native ink collection; no custom pointer engine.
- Black `#000000`, Blue `#194196`.
- Thin 2.0 / Medium 3.5 / Thick 5.0 DIP; Medium default.
- Selector changes affect future strokes only.
- Undo/Redo/Clear are dialog-local; Clear is not undoable.
- Useful ink: at least one >=2-point stroke and union bounds >=4×4 DIP.
- Transparent padding: `clamp(max(8, maxStrokeWidth*2), 8, 24)` DIP.
- Raster scale: 300/96 = 3.125.
- Existing 20M-pixel limit applies before output allocation.
- No temp signature image.
- Cancel/failure leaves PDF placement state unchanged.
