# F0.5 — Windows Print

## Objetivo

Imprimir el PDF abierto mediante el sistema estándar de Windows, incluyendo impresoras físicas y virtuales como Microsoft Print to PDF, sin añadir dependencias runtime ni una segunda pila de renderizado.

## Requisito

- `PDF-BASE-06`: Imprimir mediante Windows, incluyendo Microsoft Print to PDF.

## Alcance

- `Archivo > Imprimir...`;
- diálogo estándar `System.Windows.Controls.PrintDialog`;
- selección de impresora mediante Windows;
- imprimir todas las páginas;
- imprimir la página actual;
- imprimir un rango continuo de páginas;
- paginación WPF con `DocumentPaginator`;
- render PDFium para salida de impresión;
- ajuste proporcional al área imprimible reportada por el driver;
- Windows CI y pruebas sin requerir impresora instalada.

## Diseño KISS

### `PdfPrintRange`

Representa un rango inclusivo de índices PDF 0-based y expone factories claras:

- `All(pageCount)`;
- `Current(currentPageIndex, pageCount)`;
- `UserPages(firstPageNumber, lastPageNumber, pageCount)` para números de página 1-based del diálogo Windows.

Los rangos inválidos fallan explícitamente; no se corrigen silenciosamente.

### `PdfDocumentPaginator`

Implementa `DocumentPaginator` y produce cada página bajo demanda:

1. mapea el número lógico del trabajo al índice real del PDF;
2. renderiza esa página con PDFium;
3. crea un `BitmapSource` BGRA;
4. preserva relación de aspecto;
5. centra la página dentro del área imprimible seleccionada;
6. devuelve un `DocumentPage` al pipeline WPF/Windows.

Render de impresión inicial: **200 DPI**. Es un equilibrio deliberado entre calidad y memoria para F0.5; puede medirse/revisarse en F0.6 con documentos reales.

### Integración Windows

La UI usa `PrintDialog` nativo de WPF:

- `CurrentPageEnabled = true`;
- `UserPageRangeEnabled` cuando existe más de una página;
- `MinPage = 1` y `MaxPage = PageCount`;
- `PrintableAreaWidth/Height` como tamaño del paginador;
- `PrintDocument(paginator, description)` para enviar al spooler seleccionado.

Microsoft Print to PDF no recibe código especial: entra por el mismo selector de impresoras Windows.

## QA físico pendiente

En Windows interactivo:

1. abrir un PDF real de varias páginas;
2. `Archivo > Imprimir...`;
3. cancelar el diálogo y confirmar que no ocurre nada;
4. imprimir todas las páginas;
5. imprimir solo la página actual;
6. imprimir un rango, por ejemplo 2–4;
7. seleccionar Microsoft Print to PDF, guardar y reabrir el PDF generado;
8. comparar contenido y orden de páginas;
9. probar un PDF con página vertical y otra horizontal;
10. si existe impresora física, validar una impresión real;
11. observar memoria/latencia con un PDF pesado para decidir si 200 DPI necesita ajuste.

## Fuera de alcance

- preview de impresión propio;
- rangos múltiples no contiguos;
- impresión silenciosa/directa sin diálogo;
- presets propios de color, duplex, bandeja u orientación;
- spooler personalizado;
- XPS temporal;
- ZPL/impresión térmica.
