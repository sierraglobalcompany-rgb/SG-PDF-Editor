# F0.6 — QA / Hardening / Offline

## Objetivo

Cerrar técnicamente F0 PDF Base antes de Gate ZPL-A, corrigiendo solo huecos demostrados por auditoría de requisitos y añadiendo verificaciones automatizadas de regresión/offline.

## Requisitos de cierre

- `PDF-BASE-01`: abrir PDF local.
- `PDF-BASE-02`: render PDFium fuera del UI thread.
- `PDF-BASE-03`: anterior / siguiente / **ir a página**.
- `PDF-BASE-04`: zoom + fit page + fit width.
- `PDF-BASE-05`: cancelar renders obsoletos/priorizar visible.
- `PDF-BASE-06`: impresión Windows.
- `PDF-BASE-07`: funciones principales sin red.

## Hallazgo de auditoría

F0.2 implementó anterior/siguiente, pero no una acción de **ir a página**. Este hueco impide marcar `PDF-BASE-03` completo.

## Alcance KISS

1. Añadir `GoToPageNumber(int pageNumber)` a `PageNavigationState` con numeración visible 1-based y límites estrictos.
2. Convertir el indicador de página en un control compacto editable: página actual + `de N`; Enter navega; valor inválido restaura la página actual sin cambiar estado.
3. Reutilizar `NavigateAsync`; no crear otro flujo de render.
4. Añadir guard automatizado offline que detecte dependencias directas de red en el runtime/source del producto.
5. Ejecutar suite completa + build Windows y auditar diff final.
6. Mantener smoke físico F0.1–F0.5 como `NOT RUN` hasta escritorio Windows interactivo.

## Fuera de alcance

- thumbnails/búsqueda;
- scroll continuo;
- progressive rendering sin evidencia;
- cambios de arquitectura;
- preview de impresión;
- ZPL/firma/edición/OCR.
